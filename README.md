# Análisis de sentimientos con Python

Proyecto de aprendizaje para clasificar opiniones de clientes como **positivas o negativas** utilizando Pandas, TF-IDF y regresión logística de Scikit-learn.

## Fases del proyecto

- [Fase 1](Fase1.ipynb): primeros pasos con ocho opiniones, TF-IDF y entrenamiento de un clasificador.
- [Fase 2](Fase2_corregido.ipynb): entrenamiento y evaluación con las 60 opiniones del CSV.
- [Fase 3](Fase3_limpieza.ipynb): comparación del modelo original con limpieza de texto, stopwords y bigramas.

Las explicaciones, el código y las conclusiones están dentro de cada notebook.

## Cómo utilizarlo

Abre los notebooks en Jupyter, VS Code o Google Colab y ejecuta las celdas en orden. Para las fases 2 y 3, el archivo [dataset_opiniones_60.csv](dataset_opiniones_60.csv) debe estar disponible en la carpeta de ejecución. Si utilizas Colab, súbelo al entorno.

Dependencias: `pandas` y `scikit-learn`.

> Es un ejercicio educativo con pocos datos; las predicciones todavía pueden contener errores.
